# GenerativeAI 
* Understand different text representation techniques and compare their effectiveness. 
* Learn preprocessing, ANN architecture, forward/backward propagation, and classification.
* Apply transfer learning using pre-trained NLP models.
* Implement LSTM for sequence prediction and understand sequential learning.
* Understand sequence-to- sequence learning and encoder–decoder models.
* Implement transformer architecture for abstractive summarization.
* Explore transformer-based models (BERT/GPT) for question answering.
* Learn prompt engineering and practical use of Generative AI models for content generation.
